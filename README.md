# SILIA
## Sistem Laporan Infrastruktur Desa

SILIA merupakan platform berbasis web yang digunakan untuk memudahkan masyarakat dalam melaporkan permasalahan infrastruktur desa secara cepat, transparan, dan mudah dipantau.

---

## Tentang Project

SILIA (Sistem Laporan Infrastruktur Desa) dibuat sebagai solusi digital untuk membantu proses pelaporan berbagai masalah infrastruktur desa seperti:

- Jalan rusak
- Lampu jalan mati
- Gangguan air bersih
- Drainase
- Fasilitas umum
- Permasalahan infrastruktur lainnya

Melalui sistem ini, masyarakat dapat menyampaikan laporan dengan menyertakan informasi lokasi dan bukti foto sehingga proses identifikasi dan tindak lanjut permasalahan dapat dilakukan dengan lebih efektif.

---

## Fitur Utama

### Halaman Pengguna

### Landing Page
- Informasi mengenai SILIA
- Cara membuat laporan
- Daftar laporan terbaru

### Login
- Form masuk pengguna

### Register
- Pendaftaran akun pengguna
- Data pengguna:
  - Nama lengkap
  - Email
  - Username
  - Tanggal lahir
  - Jenis kelamin
  - Nomor telepon
  - Password

### Buat Laporan
- Pemilihan kategori laporan
- Input judul laporan
- Detail lokasi kejadian
- Deskripsi permasalahan
- Upload foto bukti
- Data pelapor

### Laporan Publik (Tahap Pengembangan)
- Melihat daftar laporan masyarakat
- Monitoring status laporan

## Pengembangan Selanjutnya

SILIA akan dikembangkan menjadi sistem berbasis full-stack dengan implementasi:

- Migrasi tampilan frontend menggunakan React JS
- Pengembangan backend menggunakan Laravel
- Integrasi database MySQL
- Sistem autentikasi pengguna
- Dashboard pengguna dan admin desa
- Pengelolaan laporan secara realtime
- Validasi dan perubahan status laporan
- Tracking progres laporan
- Penyimpanan data laporan dan bukti foto
